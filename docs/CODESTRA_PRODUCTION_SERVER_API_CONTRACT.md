# Codestra Blackbox Exporter Production Server and Native API Contract

## Authority

- Repository: `appolon1908-hue/Codestra-Blackbox-Exporter`
- Role: controlled synthetic HTTPS, TLS, DNS, TCP, ICMP, and approved gRPC evidence authority
- Canonical hostname: `blac.codestra.media`
- Central production host: `37.27.128.39`
- Status: `SOURCE_CONTRACT_PREPARED_NOT_DEPLOYED`

Blackbox Exporter owns probe modules, protocol behavior, target-safety validation, SSRF controls, runtime configuration, release evidence, and rollback. `appolon1908-hue/Codestra-Prometheus` owns target discovery, the exact destination allowlist, target labels, and the business endpoint inventory. Target addresses must not be stored in this repository.

Blackbox Exporter does not own arbitrary Internet scanning, business actions, credentials, application mutation, or the corporate target inventory.

## Native API surface

| Method | Path | Purpose | Boundary |
|---|---|---|---|
| `GET` | `/-/healthy` | exporter health | private/read-only |
| `GET` | `/metrics` | exporter self-metrics | private Prometheus scrape |
| `GET` | `/probe` | controlled synthetic probe | private; module constrained here and target supplied only by approved Prometheus configuration |

Unexpected `404`, unhandled `5xx`, arbitrary operator target selection, credential-bearing URLs, or a public unrestricted `/probe` endpoint blocks production.

## Probe security and ownership policy

- Blackbox probe modules and generic target-safety/SSRF enforcement are source-controlled in this repository.
- Exact destination discovery and allowlisting are source-controlled in `appolon1908-hue/Codestra-Prometheus`; this repository contains zero business target addresses.
- The `/probe` target parameter is generated by approved Prometheus scrape configuration, not an arbitrary operator, browser, or Internet caller.
- Resolve and validate every target before and after DNS resolution.
- Deny loopback, link-local, metadata, multicast, unspecified, private, reserved, and disallowed internal addresses unless the exact internal destination is explicitly reviewed in Prometheus for the private monitoring plane and permitted by the Blackbox safety policy.
- Protect against DNS rebinding and redirect-to-disallowed-address behavior.
- Limit methods, redirects, TLS versions, response sizes, timeouts, concurrency, and egress.
- Never accept embedded credentials, tokens, cookies, secret query strings, or arbitrary operator-supplied targets.
- Native metrics and probe endpoints remain private.

## Repository-first remediation

Preserve the old healthy exporter when a probe or security test fails. Fix module behavior, SSRF enforcement, response handling, and Blackbox runtime configuration here with regression tests; commit/push; obtain exact-head CI/review; merge normally; rebuild/sign; update the BOM; and retry. Add or change exact monitored target addresses only in `appolon1908-hue/Codestra-Prometheus`, never in this repository or only on the server.

## Safety

This document does not deploy Blackbox Exporter or activate targets. SSH changes, business writes, communications delivery, provider actions, lending, payments, and trading remain outside scope and disabled.
